# 🟪 AWS Cloud Practitioner Flashcards

Um projeto web interativo desenvolvido para auxiliar nos estudos para a certificação **AWS Certified Cloud Practitioner (CLF-C02)**.

Atualmente, o projeto está focado em **flashcards para revisão e memorização de conceitos fundamentais da AWS**, com recursos de filtragem, embaralhamento e acompanhamento dos cards mais difíceis.

> 🚧 Projeto em desenvolvimento. Novos recursos de estudo serão adicionados gradualmente.

## 🎯 Objetivo

Facilitar a revisão de conceitos importantes da AWS por meio de flashcards interativos, permitindo estudar de forma prática diretamente pelo navegador.

## ✨ Funcionalidades

* 📚 **280 flashcards** organizados por conceitos do exame CLF-C02
* 🔄 **Flip 3D** para visualizar a resposta
* ⭐ **Cards essenciais** para revisão dos principais conceitos
* ⚠️ **Cards difíceis** para marcar conteúdos que precisam de mais atenção
* 🔀 **Embaralhamento** dos flashcards
* 💾 **LocalStorage** para manter os cards difíceis salvos no navegador
* ⌨️ **Navegação por teclado**
* 📱 **Layout responsivo** para diferentes tamanhos de tela
* 🌙 **Tema Dark/Neon**

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript (Vanilla)
* LocalStorage

## 🚀 Como executar

O projeto funciona diretamente no navegador e não possui backend.

1. Clone este repositório:

   ```bash
   git clone https://github.com/wylianedamaso/aws-cloud-practitioner-flashcards.git
   ```

2. Acesse a pasta do projeto.

3. Abra o arquivo `index.html` no navegador.
